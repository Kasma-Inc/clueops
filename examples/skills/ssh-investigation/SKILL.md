# 当前目标的 SSH 调查

从工具目录及目标资源中确认获准的SSH实例，调用对应execute工具并提交远程command。多台服务器分别调用其工具实例；连接与认证由插件管理，无需读取私钥、密码或调用本地ssh。工具结果直接包含证据编号，不用local_command_evidence。

先核对远端主机身份和环境，再按错误自行发现日志、服务和查询工具；不假设一定安装了kubectl或数据库客户端。认证或连接失败时报告该来源不可用，不猜测其他主机或凭证。

按只读取证任务使用命令，实际权限由远端账号落实。保留失败、截断、时间范围与证据缺口；SSH超时或断开不能证明远端命令已终止。
