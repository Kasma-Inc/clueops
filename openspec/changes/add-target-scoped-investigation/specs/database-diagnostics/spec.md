# Spec Delta

## Purpose

让 Agent 能在目标授权的数据源中探索结构、读取必要业务数据并检查数据库运行状态，首版以 PostgreSQL 验证真实排障流程；后续数据库保留方言和能力差异，不因通用组件支持多引擎就声称全部兼容。

## ADDED Requirements

### Requirement: 查询连接只来自目标授权

系统 SHALL 只为调查提供当前目标授权的数据源和必要连接身份，MUST NOT 接受 Agent 提供的新连接串、凭证或未授权 source。共享数据库 SHALL 通过目标配置显式声明，不以同名数据库或表推断共享关系。

#### Scenario: 查询参数选择另一个数据库
- **WHEN** A 调查将数据源改为 B 的 source，或提供 B 的连接串
- **THEN** 系统在连接前拒绝请求，B 未收到查询

### Requirement: 提供结构、数据和运行诊断查询

系统 SHALL 支持授权结构探索、必要业务数据读取及运行状态查询，并向 Agent 明示数据库引擎、方言和可用诊断能力。首版 SHALL 验证 PostgreSQL 的连接、事务和锁等代表性诊断，不能将不支持或无权限的能力当作无异常。

#### Scenario: 排查 PostgreSQL 锁等待
- **WHEN** 授权账号可以读取相关运行视图，Agent 调查连接或锁等待问题
- **THEN** 工具返回允许范围内的状态证据，报告关联取得时间和数据库身份

#### Scenario: 数据库未经过验收
- **WHEN** 配置使用尚未验证的数据库引擎或其缺失某项诊断能力
- **THEN** 系统明确标明支持或验证边界，不声称已具备 PostgreSQL 的全部诊断能力

### Requirement: 只读及查询预算由实际执行边界约束

系统 SHALL 使用必要权限的数据库身份及只读查询控制，禁止生产数据写入，并限制查询耗时、返回行数、字节数和连接规模。SQL 关键词或默认 schema MUST NOT 单独作为权限依据；远端终止未确认时 SHALL 明示状态未知。

#### Scenario: 尝试写入或越权读取
- **WHEN** Agent 提交写入语句或读取未授权表、schema、数据库或危险能力
- **THEN** 请求被工具或数据库权限拒绝，不能因配置只读标签就放行越权行为

#### Scenario: 长查询被取消
- **WHEN** 查询超过服务端超时或本轮调查被取消
- **THEN** 系统停止等待并释放本轮资源，不影响其他调查；若无法确认远端停止，保留该限制说明

### Requirement: 数据库故障不阻塞其他证据源

系统 SHALL 在数据库连接失败、认证被拒或后端初始化失败时记录其不可用状态，允许其他已成功绑定的数据源继续取证，MUST NOT 切换至另一个数据库或将失败返回为空查询结果。

#### Scenario: 数据库在调查开始前已宕机
- **WHEN** 数据库无法建立连接，而集群日志与源码仍可读取
- **THEN** Agent 继续取得可用证据，报告明确说明数据库不可用及缺失的验证信息
